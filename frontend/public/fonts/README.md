# Fontes da História

Archivo variável nos títulos (peso 800, largura 125%) e Source Sans 3 variável nos parágrafos reproduzem a escolha tipográfica da referência TÒPAS, mantendo as cores do Coxinh.IA. Os arquivos são servidos localmente.

- Referência: https://bar-topas.ch/wp-content/themes/emg-topas/assets/css/main.css
- Archivo: https://github.com/google/fonts/tree/main/ofl/archivo
- Source Sans 3: https://github.com/google/fonts/tree/main/ofl/sourcesans3

As licenças SIL Open Font License 1.1 acompanham os arquivos em `archivo-OFL.txt` e `source-sans-3-OFL.txt`.
